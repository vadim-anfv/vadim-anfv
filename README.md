I'm Vadim Anufriev. I work on [bdk-cli](https://github.com/bitcoindevkit/bdk-cli) under an [OpenSats](https://opensats.org/) grant, and send occasional patches to [rust-miniscript](https://git.rust-bitcoin.org/rust-bitcoin/rust-miniscript).

I build [stackwalk](https://vadim.rs/stackwalk/), a Bitcoin Script debugger that runs in the browser: write a policy, miniscript or descriptor, pick a spend path, and walk the script with the stack at every opcode. It started as a way to check my own reading of the interpreter, so treat it as a learning aid rather than a reference ([source](https://github.com/vadim-anfv/stackwalk)).

Notes on descriptors, miniscript and taproot: [vadim.rs/blog](https://vadim.rs/blog/).
